# 报岗倒计时 · 原生安卓 APP 打包说明

这是一个**真正的安卓 APP**（Kotlin + 原生 AlarmManager），锁屏 / 后台都能准点响铃+震动+全屏提醒，
比网页版可靠得多。下面是用 **GitHub Actions 免费自动出包** 的步骤，你最后只下载安装即可，**不需要装任何开发工具**。

---

## 一、准备（只需做一次）

1. 注册一个 GitHub 账号（免费）：https://github.com/signup
2. 登录后，新建一个仓库（Repository）：
   - 点右上角 **+ → New repository**
   - 仓库名随便填，比如 `baogang-app`
   - 选 **Public**（公开，免费；代码只是个计时器，无所谓）
   - 不要勾 "Add a README" 之类的，保持空仓库
   - 点 **Create repository**

## 二、把工程文件传上去

> 把本文件夹（`android_app/`）里的**所有内容**上传到仓库根目录（不要套一层 `android_app` 文件夹）。

最简单的方式（网页拖拽，不用装 Git）：
1. 进入你刚建的仓库，点 **Add file → Upload files**
2. 把本文件夹里的这些文件和文件夹一起选中拖进去：
   - `build.gradle`、`settings.gradle`
   - `app/`（整个文件夹）
   - `.github/`（整个文件夹）
3. 页面底部填个说明（如 `init`），点 **Commit changes**

## 三、自动编译出包

1. 上传后，点仓库顶部的 **Actions** 标签
2. 会看到一个名为 **Build APK** 的工作流在跑（第一次可能要点一下 "I understand..." 启用）
3. 等几分钟，显示绿色 ✅ 即成功
4. 点进该次运行 → 右侧 **Artifacts** → 下载 **app-debug-apk**（这就是安装包 `app-debug.apk`）

> 以后你（或我）改了代码重新上传，Actions 会自动重新出包。

## 四、安装到手机

1. 把 `app-debug.apk` 传到安卓手机（微信文件传输/数据线/U盘都行）
2. 手机打开它，按提示**允许"未知来源"安装**（不同手机叫法略有不同）
3. 装好后桌面就有"报岗倒计时"图标，点开即用

### 首次使用注意
- 点「白班」或「夜班」开始，会弹出**"允许精确闹钟"**的系统设置页 → 找到"报岗倒计时"→ 允许（否则只能近似提醒）
- 报警走**系统闹钟音量**，和铃声音量无关；如果一点声音都没有，去手机"闹钟"App 把闹钟音量调大
- 想测试声音：点 **🔊 测试响铃**
- 锁屏也能全屏响铃+震动；息屏后到点照样提醒（这是网页版做不到的）

## 常见问题
- **构建失败（红色❌）**：把 Actions 里红色步骤的报错截图发我，我改代码后你重新上传即可。
- **iPhone 装不了**：苹果不允许这样装第三方 APP，iPhone 用户只能继续用网页版。
- **想换图标/名字/配色**：告诉我，我改完你重新上传出包。
